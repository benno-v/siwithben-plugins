# SI with Ben — Claude Code plugins

Practical Claude Code plugins for project managers and busy professionals, from the YouTube channel [SI with Ben](https://www.youtube.com/@SIwithBen).

*By Ben Vermeulen, @SIwithBen.*

## Install

In Claude Code, add this marketplace once:

```
/plugin marketplace add benno-v/siwithben-plugins
```

Then install any plugin from it:

| Plugin | What it does | Install |
|---|---|---|
| [pm-status-report](plugins/pm-status-report) | Rough notes → consistent weekly status report with RAG rating | `/plugin install pm-status-report@siwithben-plugins` |
